# Introduction to Cybersecurity – Udacity Nanodegree

This repository contains hands-on cybersecurity projects completed as part of the **Udacity Introduction to Cybersecurity Nanodegree**.

## Projects

The projects cover different areas of cybersecurity, including:

* Network security
* Risk assessment
* Cryptography
* Incident response

## Skills Gained

* Threat identification and mitigation
* Security risk assessment
* Encryption and key management
* Incident detection and response
