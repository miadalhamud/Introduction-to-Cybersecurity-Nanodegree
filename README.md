Introduction to Cybersecurity – Udacity Nanodegree
--------------------------------------------------------------------------------------------------------------------------------------------
This repository contains hands-on cybersecurity projects completed as part of the Udacity Nanodegree: Introduction to Cybersecurity program. Each project demonstrates practical skills and concepts essential to building a strong cybersecurity foundation.

Skills Gained
-----------------------------------------------------------------------------------------------------------------------------------------
* Threat identification and mitigation
* Security risk assessment
* Encryption and key management
* Incident detection and response strategies
